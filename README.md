# CloakBrowser one-click deploy

> CloakBrowser (GitHub 19.6K stars) is a stealth Chromium browser.
> This repo provides Chinese one-click deployment for cross-border e-commerce.

## Features
- Chinese docs
- Docker one-click setup
- Amazon/TikTok/Social profiles
- Proxy integration
- VNC remote desktop
- DevTools API

## Quick Start

git clone https://github.com/njbhv/cloak-chinese-kit
cd cloak-chinese-kit
docker compose up -d
