# Twitter/X 流量发帖教程

## 核心原则

中文出海圈推文要火，3 个要素缺一不可：
1. **钩子（Hook）** — 前 2 行抓注意力
2. **价值（Value）** — 免费开源 + 真实问题
3. **行动（CTA）** — 链接 + 付款方式
